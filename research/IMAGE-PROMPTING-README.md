## How to Use These Guides

### First Time?
1. Read Master Guide **Quick Start** section (5 min)
2. Choose your tool (ChatGPT or Gemini)
3. Read tool-specific guide **overview** (10 min)
4. Pick a template from **Ready-to-Use** section (1 min)
5. Generate image using template prompt (5-10 min)
6. Check **Common Failures** if result is wrong (2 min)

### Regular Use?
- Keep **Quick Reference Card** (at end of Master Guide) handy
- Bookmark the **Ready-to-Copy Templates** section
- Reference **Failure Modes** table as needed
- Switch tools based on this decision: text-heavy? → ChatGPT | fast variants? → Gemini

### Building Full Campaign?
- Follow **5-Step Master Workflow** in Master Guide
- Use **Phase 1-4 workflow** in tool-specific guide
- Use **Production Checklists** before final export
- Keep **Platform-Specific Guidance** nearby for poster vs social vs slides

## Notes for Sahaja Yoga Project

### Key Strengths in These Guides

1. **Indian School Authenticity** — Every template emphasizes real Indian school context, uniforms, classrooms, teachers
2. **Trust & Safety Language** — Specific vocabulary for building principal, teacher, parent confidence
3. **Secular/Science-Based Framing** — Explicit guidance to avoid spiritual/religious imagery (appropriate for school proposals)
4. **Platform-Ready Templates** — Aspect ratios and sizes for poster print, WhatsApp mobile, PowerPoint slides, social media
5. **Text Handling** — Practical guidance: generate WITHOUT text, add final Marathi/English/Hindi in Canva
6. **Workflow Integration** — 4-phase process from exploration through final export

### Recommended Starting Point

For Sahaja Yoga school outreach, start with:

1. **Master Guide → Quick Start** (decide: ChatGPT or Gemini)
2. **Master Guide → SET A, B, or C** (pick template for your use case)
3. **Copy template prompt**
4. **Generate in ChatGPT or Gemini**
5. **Check Master Guide → Failure Modes** if needed
6. **Export and add text in Canva** (never rely on in-image text)
