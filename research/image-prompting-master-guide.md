## Recommended Workflow

### Phase 1: Exploration (Gemini Flash)
```
1. Use Gemini 3.1 Flash (fastest, cheapest)
2. Generate 3-5 directions
3. Test compositions, moods, lighting
4. Get feedback
→ SELECT BEST DIRECTION
```

### Phase 2: Refinement (Gemini Pro or DALL-E 3)
```
5. Generate final variations of best direction
6. Use as reference image for consistency
7. Test different aspect ratios (poster, status, proposal)
8. Finalize palette and style
→ SELECT FINAL AESTHETIC
```

### Phase 3: Production (Platform-Specific)
```
9. For poster with text → DALL-E 3 (better text)
10. For WhatsApp status → Gemini (conversational tweaks)
11. For proposal cover → Either (both excellent quality)
12. For social variants → Gemini (faster multi-gen)
→ READY FOR EXPORT
```

### Phase 4: Text Addition (Design Tool)
```
13. Export all images WITHOUT text
14. Add final Marathi/English/Hindi text in Canva/Figma
15. Ensure 100% accuracy and placement
→ FINAL ASSETS
```

## Universal Prompt Structure

Every effective prompt has three layers:

### Layer 1: Foundation (What & Why)
```
Create [ASSET TYPE] for [AUDIENCE] to [PURPOSE].

Example:
Create a school proposal poster for principals and teachers 
to convince them to implement our meditation program.
```

### Layer 2: Content (Who, What, Where, When)
```
Subject: [WHO/WHAT in image, AGE, ACTION]
Context: [WHERE, WHEN, ENVIRONMENT, CULTURAL DETAILS]
Composition: [LAYOUT, ASPECT RATIO, PLACEMENT, SPACE]

Example:
Subject: Indian school children (8-12 years old) sitting peacefully 
in meditation with eyes gently closed, authentic school uniforms.

Context: Bright authentic Indian school classroom, morning natural 
daylight through windows, wooden desks, whitewashed walls.

Composition: Vertical 1024x1536, children in lower-center, 
open space at top for title/text.
```

### Layer 3: Style (How It Looks & Feels)
```
Style: [PHOTOGRAPHY/ILLUSTRATION STYLE], [LIGHTING], [PALETTE], [MOOD]

Constraints: [WHAT YOU WANT], [WHAT TO EXCLUDE]

Example:
Style: Soft high-key documentary photography, natural window light, 
pastel palette (soft white, sky blue, pale green, warm cream), 
innocent and peaceful mood.

Constraints: Authentic Indian school setting, no religious symbols, 
no exaggerated yoga poses, no watermark, trustworthy for administrators.
```

### 6. Lighting Specification (Complete Reference)

#### High-Key (Bright, Minimal Shadows)
**When:** School safety, children, peaceful themes
**Language:** "High-key bright lighting", "minimal shadows", "even illumination"
**Effect:** Innocent, safe, trustworthy, approachable

#### Soft Window Light (Directional but Diffused)
**When:** Authentic classroom realism, documentary feel
**Language:** "Soft light from left through classroom window", "directional but diffused"
**Effect:** Natural, honest, realistic, documentary

#### Golden Hour (Warm Evening/Morning)
**When:** Peaceful meditation themes (not school outreach)
**Language:** "Golden hour light", "warm natural daylight", "sunset/sunrise"
**Effect:** Peaceful, warm, dreamy, less formal

#### Diffused Daylight (Even, All-Directional)
**When:** Neutral, professional, balanced lighting
**Language:** "Diffused natural daylight", "even illumination from all sides"
**Effect:** Professional, safe, balanced

#### Gentle Rim Light (Subtle Backlight)
**When:** Focus themes, separation between subject and background
**Language:** "Gentle rim light from behind", "subtle backlight for separation"
**Effect:** Professional, dimensional, emphasis on subject

#### Avoid for School Outreach
❌ "Dramatic lighting" (too theatrical, not trustworthy)
❌ "High contrast" (too intense, intimidating)
❌ "Shadows" (creates doubt, seems hidden)
❌ "Neon/artificial light" (too modern/edgy for school)
❌ "Spotlight" (too staged, performative)

### 7. Color Palette Specification (Complete Reference)

#### Base Palette (Always Start With)
```text
Palette: soft white, sky blue, pale leaf green, warm cream, 
gentle yellow, natural wood tones.
```

This palette works across all Sahaja Yoga school outreach because:
- White: clean, innocent, trustworthy, academic
- Sky blue: calm, peace, sky/nature, non-threatening
- Pale green: growth, health, nature, healing
- Warm cream/yellow: approachable, warm, human
- Wood tones: authentic, real, natural

#### How to Specify Color Saturation

| Term | Effect | Example |
|------|--------|---------|
| **Pastel** | Soft, light, desaturated | "Pastel sky blue" |
| **Soft** | Gentle, not vibrant | "Soft green" |
| **Muted** | Calm, understated | "Muted teal" |
| **Desaturated** | Reduced color intensity | "Desaturated purple" |
| **Pale** | Light version of color | "Pale lavender" |
| **Warm** | Leaning toward yellow/orange | "Warm cream" |
| **Cool** | Leaning toward blue/green | "Cool white" |

#### Alternative Palettes

**For Meditation/Inner Focus:**
```text
Pristine white, pale blue, light sage green, warm beige, 
soft lavender, natural materials.
```

**For Engagement/Energy (while soft):**
```text
Bright white, sky blue, fresh green, warm golden yellow, 
soft coral, natural earthy tones.
```

**For Peace/Trust (counselor aesthetic):**
```text
Soft white, pale teal, light green, warm tan, soft purple, 
natural wood.
```

#### How NOT to Specify Color

| Don't Say | Do Say |
|-----------|--------|
| "blue" | "soft sky blue" or "pale blue" |
| "green" | "pale leaf green" or "light sage" |
| "warm colors" | "palette of warm cream, golden yellow, light green" |
| "pastel colors" | "pastel white, sky blue, soft yellow, pale green" |
| "calm colors" | "soft white, pale blue, pale lavender, warm cream" |

### 9. Cultural Context Specification

#### India-Specific Details to Request

```text
Indian school classroom with authentic details:
- Whitewashed walls or painted walls typical of Indian schools
- Wooden desks and benches (not plastic modern)
- Indian school uniforms (blue and white, typical style)
- Educational posters in Hindi/English
- Wooden chalkboard or basic whiteboard
- Natural light through small windows
- Real school materials and notebooks
- Indian teacher and children
```

#### What to Avoid in Cultural Context

❌ Western classroom assumptions (carpet, advanced tech, etc.)
❌ Stereotypical yoga imagery or exaggerated poses
❌ Religious symbols or deity imagery
❌ Over-spiritualized framing
❌ "Model-perfect" or glamorous styling
❌ Stock photo aesthetic (doesn't look like real schools)

#### Authenticity Language

```text
"Authentic Indian school environment with real details, 
secular school wellness program (not spiritual), 
science-informed meditation approach, honest and practical, 
trustworthy for school administrators and parents"
```

### 10. Negative Constraints (What to Exclude)

Always include explicit constraints for school outreach:

```text
Constraints:
- No religious symbols, deity imagery, or spiritual iconography
- No exaggerated yoga poses or flexibility displays
- No watermark, copyright notice, or branding
- No distorted hands, fingers, text, or anatomy
- No extra text beyond what's specified
- No clutter or excessive background details
- No artificial filters or overly styled appearance
- No mystical effects, auras, or supernatural elements
- No violence, scary content, or inappropriate material
- No stock photo aesthetic (must look real and authentic)
```

## Side-by-Side Tool Comparison

### ChatGPT / DALL-E 3

**Strengths:**
- ✅ Excellent text placement in images (poster headlines)
- ✅ Better handling of complex poster layouts
- ✅ Consistent character/object across images
- ✅ Maximum artistic control and style precision
- ✅ Built-in ChatGPT refinement loop (conversational prompts)
- ✅ High-quality single assets with few retries needed

**Weaknesses:**
- ❌ Slower iteration for variants
- ❌ No reference image support for consistency
- ❌ Less effective at Indian cultural authenticity
- ❌ Brand/character consistency drifts more across generations
- ❌ Text rendering still imperfect (not pixel-perfect)

**Best For:** Final poster with text, complex layouts, single best-quality assets

**Cost:** Medium-High
**Speed:** Medium
**Quality:** Highest
**Ease:** Medium (requires detailed prompting)

---

### Google Gemini / Imagen

**Strengths:**
- ✅ Fastest iteration (conversational refinement)
- ✅ Multi-variant generation in one request
- ✅ Excellent Indian cultural understanding
- ✅ Reference image support (up to 14 images for consistency)
- ✅ Interactive conversational UI reduces friction
- ✅ More affordable for high-volume generation
- ✅ Better at understanding context and intent

**Weaknesses:**
- ❌ Text rendering less reliable for posters
- ❌ Placement variation on text elements
- ❌ Can't guarantee exact text position
- ❌ Newer models don't support negative prompts

**Best For:** Exploration, quick variants, reference consistency, Indian authenticity

**Cost:** Low-Medium
**Speed:** Fastest
**Quality:** Very High
**Ease:** Easy (conversational, forgiving)

| Problem | Root Cause | Solution |
|---------|-----------|----------|
| Text misspelled or broken | Model struggles with exact characters | Use fewer words (max 15), regenerate, or add text in Canva |
| Layout doesn't match description | Composition too complex | Simplify to: "children lower third, space above", avoid multiple focal points |
| Looks too glamorous/stock photo | Beauty/glamour bias | Request "candid unposed", "honest faces", "real classroom", "imperfect details" |
| Mood too dark/spiritual | Lighting misinterpreted or model defaulting | Say "high-key bright", "no shadows", "innocent mood", explicitly "secular wellness" |
| Faces too perfect/polished | Model's beauty bias | Request "candid natural expressions", "unposed", "real people", "honest" |
| Hands distorted | Complex hand anatomy | Keep hands simple, in background, or avoid close-ups |
| Wrong cultural context | Generic Western classroom | Say "Indian school classroom", "school uniforms", "authentic details", name specific items |

#### Gemini Failures

| Problem | Root Cause | Solution |
|---------|-----------|----------|
| Text not rendering | Text too long or complex | Keep to 25 characters max, 1-2 words, or remove text entirely |
| Composition off-center | Placement instructions unclear | Be very specific: "children centered", "right side blank", "top 1/3 clear" |
| Style inconsistent across images | No reference image used | Upload previous successful image as reference for next generation |
| Too spiritual/mystical | Default meditation → yoga stereotype | Explicitly say "secular school wellness", "no religious symbols", "science-informed" |
| Looks unreal/plastic | Default to idealized output | Request "candid", "unposed", "real expressions", "honest", "imperfect details" |
| Indian context missing | Generic classroom assumption | Specify "authentic Indian school", name details (uniforms, desks, materials) |

## Platform-Specific Guidance

### For School Posters (Printed)

**Best Tool:** ChatGPT (if text needed) or Gemini Pro (if iterations needed)
**Size:** 1024x1536 (4:5) or 1200x1500 (A4-ish)
**Text:** Generate WITHOUT text, add in Canva for reliability
**Palette:** Soft white, sky blue, pale green, warm cream (stays true when printed)
**Print Considerations:**
- Use high-resolution generation (if available)
- Save as TIFF or high-quality JPEG
- Test print on small scale first
- Confirm colors match expectation

### For WhatsApp Status (Mobile)

**Best Tool:** Gemini (fast, good mobile context understanding)
**Size:** 1080x1920 or 9:16 aspect ratio
**Key:** Avoid important content in top 1/6 and bottom 1/4 (where UI appears)
**Palette:** All palettes work; soft colors appear less aggressive on mobile
**Mobile Considerations:**
- Test on actual phone before sharing
- Avoid small text (WhatsApp compresses)
- Keep composition simple
- Leave safe zones at top and bottom

### For Proposal PowerPoint Slides

**Best Tool:** Either (Gemini for fast, ChatGPT for control)
**Size:** 1920x1080 (16:9 standard PowerPoint)
**Layout:** Subject on left, space on right for title
**Text:** Generate WITHOUT text, add in PowerPoint for alignment
**Presentation Considerations:**
- Ensure text overlay will be visible
- Match school colors if using branded template
- Test display on projector screen
- Consistent with other slide visuals

### For Social Media (Facebook, Instagram, LinkedIn)

**Best Tool:** Gemini (good at social context, fast variants)
**Sizes:** 1024x1024 (square), 1200x627 (landscape), 1080x1920 (vertical)
**Captions:** Generate WITHOUT text (add in social platform post)
**Engagement Considerations:**
- Square posts get better reach on most platforms
- Include caption text in post, not image
- Soft colors less aggressive on feeds
- Authentic/documentary style outperforms stock photos

## Prompt Engineering Tips & Tricks

### Power Words That Work

| Effect Wanted | Use These Words |
|---------------|-----------------|
| **Authenticity** | authentic, real, genuine, unposed, candid, honest |
| **Trust** | trustworthy, warm, kind, safe, professional, appropriate |
| **Innocence** | innocent, pure, gentle, open, unguarded, childlike |
| **Peace** | peaceful, serene, calm, tranquil, restful, gentle |
| **Quality** | professional, high-quality, fine detail, well-composed, editorial |
| **Realism** | documentary, authentic, real, unglammed, honest, imperfect |
| **Softness** | soft, gentle, delicate, muted, pastel, diffused |

### Structure That Works

**BAD (vague):**
```
Create an image of children meditating at school.
```

**GOOD (specific):**
```
Create a school proposal poster for a meditation program.
Scene: Indian school children (8-12 years old) in authentic uniforms 
sitting peacefully in meditation with eyes gently closed, teacher nearby.
Style: Soft documentary photography, high-key natural light, 
pastel palette (soft white, sky blue, pale green).
```

### Iteration Strategy

**First Prompt:** Start with template from this guide
**Second Prompt:** "Keep everything the same but make [ONE specific change]"
**Third Prompt:** Reference previous image: "Similar to the image I shared, but [small adjustment]"

### Reference Image Power

Adding a reference image to Gemini (or ChatGPT with image support) is like giving the model a style guide:

```
[Image attached]

Create a similar composition but showing [different subject].
Keep the same visual style, lighting, and pastel palette.
```

This is 10x more effective than describing the style with words.

## Budget Optimization

### Cost-Effective Workflow

1. **Exploration Phase (cheapest):** Gemini Flash = $0.05-0.15 per image
   - Generate 5-10 directions quickly
   - Discard 80%, keep best 20%

2. **Refinement Phase (medium):** Gemini 3.1 or ChatGPT = $0.10-0.30 per image
   - Polish 2-3 promising directions
   - Generate platform variants (square, story, slide, poster)

3. **Final Production (careful):** Gemini Pro or DALL-E 3 = $0.30-1.00 per image
   - Generate final approved versions
   - Use as reference for consistency
   - Save for future reuse

### Money-Saving Tips

✅ Generate WITHOUT text (add in Canva) = no text rendering retries
✅ Use Gemini for variants instead of ChatGPT = 10x cheaper
✅ Reuse reference images across multiple posters = fewer new generations
✅ Single strong direction = fewer wasted test generations
✅ Use smaller model for exploration (Flash not Pro) = 60% cost savings

## The 5-Step Master Workflow

### Step 1: Plan (2 min)
```
□ Asset type: [poster / status / slide / social]
□ Audience: [principals / teachers / parents / students]
□ Purpose: [trust / engagement / evidence / awareness]
```

```
□ Save all variants
□ Select best direction
```

```

□ Generate refined versions

```

```
□ Export at correct resolution
□ Verify no watermarks/distortions
```

### Step 5: Polish (5-10 min in Canva)
```
□ Open in Canva/Figma
□ Add final text in Marathi/English/Hindi
□ Verify legibility and placement
□ Export for distribution
```
