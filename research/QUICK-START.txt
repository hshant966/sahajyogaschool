================================================================================
TOOL SELECTION GUIDE
================================================================================

CHOOSE CHATGPT/DALL-E 3 IF:
  ✓ Text placement in image is critical (posters with headlines)
  ✓ You need maximum artistic control and precision
  ✓ Complex poster layouts with multiple design elements
  ✓ Final high-quality single asset more important than variants
  ✓ Brand/character consistency without reference images

CHOOSE GOOGLE GEMINI IF:
  ✓ You want fast iteration (3-5 variants quickly)
  ✓ Indian school authenticity is priority
  ✓ Budget matters (Gemini cheaper for volume)
  ✓ Reference image consistency across multiple assets
  ✓ Conversational refinement preferred (interactive tweaks)

================================================================================
RECOMMENDED WORKFLOW
================================================================================

PHASE 1: EXPLORATION (Gemini Flash - cheapest, fastest)
  - Generate 3-5 quick directions
  - Test different moods, compositions, child ages
  - Save all, select best direction
  Time: ~10 min, Cost: ~$0.25

PHASE 2: REFINEMENT (Gemini 3.1 or ChatGPT)
  - Refine best variant
  - Generate platform variants (square, status, slide, poster)
  - Finalize palette and style
  Time: ~15 min, Cost: ~$0.50-1.00

PHASE 3: PRODUCTION (ChatGPT if text-heavy, Gemini if variants)
  - Generate final approved versions
  - Export at correct resolution
  - Verify no watermarks/distortions
  Time: ~10 min, Cost: ~$0.50-1.00

PHASE 4: POLISH (Canva/Figma - 5 min)
  - Open exported image in Canva
  - Add final Marathi/English/Hindi text
  - Export for distribution

TOTAL TIME: 40-50 min per asset
TOTAL COST: $1.25-2.50 per asset (or less with Gemini Flash throughout)

KEY SPECIFICATIONS
================================================================================

ASPECT RATIOS (Use These Exact Sizes):
  School Poster:        1024 x 1536 (4:5, vertical, print)
  WhatsApp Status:      1080 x 1920 (9:16, mobile vertical)
  Proposal Slide:       1536 x 1024 (16:9, landscape)
  Social Square:        1024 x 1024 (1:1, Instagram/Facebook)
  Website Banner:       1536 x  672 (21:9, wide horizontal)

STANDARD PALETTE (Always Use):
  Soft white, sky blue, pale leaf green, warm cream, 
  gentle yellow, natural wood tones

STANDARD LIGHTING (Always Use):
  Soft high-key natural daylight, gentle window light, 
  no harsh shadows, innocent and peaceful mood

STANDARD CONSTRAINTS (Always Include):
  No religious symbols, no watermark, no exaggerated yoga poses,
  authentic Indian school context, secular wellness program,
  no mystical effects, trustworthy for administrators and parents

================================================================================
TEXT HANDLING RULE
================================================================================

DO NOT:
  ✗ Include complex text in generated image
  ✗ Rely on AI text rendering for accuracy
  ✗ Expect perfect placement of text in image

DO THIS INSTEAD:
  ✓ Generate image WITHOUT text
  ✓ Export clean background image
  ✓ Open in Canva or Figma
  ✓ Add final Marathi/English/Hindi text there
  ✓ Perfect placement and legibility guaranteed

Text Limit (if you must include in image): 25 characters, 1-2 words max

COMMON MISTAKES (How to Fix)
================================================================================

Image looks too spiritual/religious:
  → Add to prompt: "secular school wellness program", 
    "no religious symbols", "science-informed meditation"

Image looks too stock photo / glamorous:
  → Add to prompt: "candid unposed", "honest faces", 
    "real classroom", "imperfect details", "authentic"

Text is misspelled or broken:
  → Solution: Don't use in-image text, add in Canva instead

Image lacks Indian school context:
  → Add to prompt: "authentic Indian school classroom", 
    name specific details (uniforms, desks, materials)

Hands look distorted:
  → Keep hands simple, in background, or avoid close-ups

Lighting too dark:
  → Add: "high-key bright", "no shadows", "innocent mood"
