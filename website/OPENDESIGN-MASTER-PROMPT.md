**Style direction:** Warm science. Like a premium Indian health research institute website. NOT clinical white. NOT spiritual golden. Clean editorial grid with intentional whitespace. Credible and warm simultaneously.

**Anti-AI-Slop Rules (MANDATORY):**
- NO purple-to-blue gradients anywhere
- NO centered hero with generic tagline and gradient blob
- NO "modern" rounded corners on everything uniformly
- NO uniform card grid with equal spacing and no hierarchy
- NO safe gray-on-white styling with one decorative accent
- NO stock photo placeholder aesthetics
- Design choices must be intentional and specific to this product

**Required design qualities (minimum 5 of these):**
1. Clear hierarchy through scale contrast (hero headline vs body text — big difference)
2. Intentional rhythm in spacing — sections breathe differently, not uniform padding
3. Depth through the 3D particle background, card shadows, layered elements
4. Typography with character — DM Serif Display for editorial weight
5. Color used semantically — green = credibility/nature/science, gold = authority/achievement
6. Hover states that feel designed — cards lift, buttons shift color smoothly
7. Grid-breaking elements — stat numbers large enough to break the text grid
8. The 3D neural network creates atmosphere without distraction

**No:** Purple gradients, generic hero blobs, stock photo aesthetics, religious motifs, Om symbols, lotus flowers, chakra diagrams, Sanskrit text, auras, mystical effects, uniform rounded corners everywhere, identical card sizes throughout.

## TECHNICAL REQUIREMENTS

- Single HTML file with all CSS and JS inline (self-contained, no build tools)
- Google Fonts: DM Serif Display + DM Sans via @import
- Smooth scroll behavior
- Sticky navigation — no shadow at top, subtle drop-shadow appears after 50px scroll
- Mobile responsive (breakpoints: 375, 768, 1024, 1440)
- Hover states on ALL cards, buttons, nav links
- Form validation (required fields, Indian phone format 10 digits)
- NO religious imagery, symbols, or Sanskrit text anywhere

### 3D HERO — Three.js Neural Network Particle System
The hero section MUST have a live 3D animated background using Three.js (CDN):
- Load Three.js from CDN: https://cdnjs.cloudflare.com/ajax/libs/three.js/r128/three.min.js
- Canvas fills full hero background, z-index behind content
- Particle system: 200 small glowing dots (color: #52B788 accent green, opacity 0.6)
- Particles connected by thin lines when within distance threshold (like a neural network / brain connectivity diagram)
- Slow gentle rotation of entire particle system
- Mouse movement causes subtle parallax shift of particles
- On mobile: reduce to 80 particles, disable mouse parallax
- Particles represent "brain connectivity" — reinforces neuroscience message
- NOT mystical, NOT spiritual — pure science visualization
- Warm cream background #FAFAF7 shows through, particles float above it

### GSAP SCROLL ANIMATIONS
Use GSAP from CDN: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/gsap.min.js
Plus ScrollTrigger: https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.2/ScrollTrigger.min.js

Apply these animations:
- Hero headline: words fade up staggered on load (0.1s stagger per word)
- Trust bar: slides in from left on scroll
- Stats section: numbers count up from 0 when scrolled into view (6 → "6 Weeks", 0 → "50+", 0 → "39,603", 0 → "120+")
- Cards: fade up with stagger as section enters viewport
- Brain science section: left text slides in from left, right illustration slides in from right
- Process steps: reveal left to right in sequence on scroll
- CTA section: scale up from 95% to 100% on entry

All animations: ease "power2.out", duration 0.6-0.8s, no jarring snaps.
