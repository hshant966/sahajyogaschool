# 5 TIPS FOR BEST CHATGPT IMAGE RESULTS

1. **Text is Fragile — Generate Clean Images, Add Text in Canva Later**  
   ChatGPT can render text, but accuracy is ~70%. For posters requiring exact wording, generate the image WITHOUT text, then overlay your final copy in Canva/Figma. Guarantees legibility and control. For WhatsApp status, if text is critical, generate image-only and add text in Canva.

2. **Specify Color Palettes with Hex Codes, Not Vague Adjectives**  
   DON'T say "use cool colors". DO say "soft sky blue (#87CEEB), pale leaf green (#90EE90), warm cream (#FFFDD0)". ChatGPT responds better to concrete hex values than descriptive language. Always include 4-5 specific colors.

3. **Use "Documentary Photography" + Specific Lens Language for Realism**  
   Instead of "realistic classroom," say "soft high-key documentary photography, 35mm lens, natural window light, no glamorization, candid unposed expressions." This anchors the model to a photographic tradition rather than generic realism.

4. **Reserve Image Space for Text — Don't Embed Long Copy**  
   If text is needed, explicitly state "open clear space in [top/bottom/left] third for text overlay" and specify dimensions or percentage. This trains the model to leave room. Generate image-only, then add final text in design software.

5. **Use "Secular School Wellness" Language to Prevent Spiritual Drift**  
   ChatGPT defaults to stereotypical meditation imagery (auras, mystical effects, deity-like figures). Counter this EVERY prompt: "secular school wellness communication, no religious symbols, science-informed focus, honest documentary style, NOT spiritual." Explicit constraint language prevents model drift.
