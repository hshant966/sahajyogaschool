## PRO TIPS FOR BEST RESULTS

1. **Text accuracy:** If text renders wrong, say "regenerate keeping same image but fix text: [exact text]"
2. **Consistency:** Generate all posters in one session — ChatGPT remembers style within session
3. **Refine:** After first generation say "same style, make children look more Indian / make colors softer / make text bigger"
4. **No text option:** Generate image without text → add in Canva for perfect text control
5. **Indian faces:** Always specify "Indian children, Indian school setting, diverse skin tones, school uniforms"
6. **Religious concern:** Always end with "No religious symbols, no deities, no spiritual paraphernalia" — critical for school acceptance
